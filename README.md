# DSA in C++

A repository containing Data Structures and Algorithms (DSA) solutions and notes in C++.

## Topics Covered

- `01-Basics` - Variables, Datatypes, Operators, Input/Output
- `02-Conditionals` - If-Else, Switch, Ternary Operators
- `03-Loops` - For, While, Do-While, Number Problems
- `04-Pattern-Printing` - Patterns, Triangles, Pyramids, Spirals
- `05-Functions` - Functions, Scope, Default Arguments, Overloading
- `06-Pointers` - Pointers, References, Double Pointers
- `07-Time-and-Space-Complexity` - Big-O Analysis and Notes
- `08-Arrays` - 1D Arrays, Vectors, Two Pointers
- `09-2D-Arrays` - Matrices, Multiplications, Spirals
- `10-Sorting` - Bubble Sort, Selection Sort, Insertion Sort
- `11-Searching` - Binary Search and Variations
- `12-Strings` - String Methods, Substrings, Anagrams
- `13-Recursion` - Recursion Trees, Paths, Classic Problems
- `14-Object Oriented Programming` - Class, Objects, Object Pointer
- `15-STL` - Vector , Deuqe
- `16-Linked List` - Node , Linked Creation

## How to Run

Compile and run using `g++`:

```bash
g++ filename.cpp -o solution
./solution
```
